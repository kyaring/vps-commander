## 2. 进行中

- 各客户端迁移到命名令牌，观察 legacy 调用归零后关闭或轮换 legacy 密钥。

## 3. 待开发（v2.2 Phase C）

- **设备接入**：一次性注册令牌（30 分钟、单次使用、绑定设备名）、`pending / online / offline / revoked` 状态、标签分组、重命名、Agent 版本落后标记。
- **通知规则**：资源阈值、版本落后、拒绝激增、令牌创建 / 吊销、新 IP 首次使用、高风险操作、审计积压；失败重试与投递记录。
- **审计分析**：按操作人 / 设备 / 动作的趋势、失败率、Top 列表；规则化异常检测；可选只读 `log_query`（`logs:read`）。

## 4. 已知遗留

- Hub 主机上的执行端以 root 运行，对 Hub 主机授予读文件 / exec / 写文件即等同管理员；后续计划 Agent 非 root 化并隔离 Hub 密钥与数据目录。
- `EffectiveRisk` 对已注册在线设备回退到全局等级（这是设计行为）；未注册 / 离线设备在授权层被拒绝。
- 会话结束后再次 `Kill()` 仍可能向原进程组发信号（理论上的 PGID 复用风险，低）。
- 内嵌 `openapi.json` 的 `servers` 为固定地址，自部署时需按实际域名修改（计划改为按请求 Host 动态生成）。
- 仓库尚未包含 `LICENSE` 文件。
