## 一、问题
internal/executor 是每台节点执行命令、读写文件、管理交互会话的核心，包覆盖率只有 50.1%。
`Local.Run`、`cappedBuffer.Write`、`ReadMultipleFiles`、`CreateDirectory`、`MoveFile`、`Session.Stdin`、`Session.Expired`，以及 `SessionManager` 的 `Get/Remove/List/Stop/Cleanup` 覆盖率都是 0%。超时、输出截断、会话上限一旦被改坏，没有测试能发现。

## 二、要求（只加测试，不改任何非测试代码）
1. `cappedBuffer.Write`：max ≤ 0 时丢弃全部内容但返回 len(p)、nil；max=5 时连续写 "abc" 和 "defgh"，两次都返回各自的 len(p)，最终内容为 "abcde"。
2. `Local.Run`：
   a. `echo hi` → ExitCode 0，Stdout "hi\n"；
   b. `echo err 1>&2; exit 3` → ExitCode 3，Stderr "err"（已去首尾空白）；
   c. workdir 设为 t.TempDir() 时 `pwd` 输出该目录（比较时对两边做 filepath.EvalSymlinks）；
   d. MaxOutput=10 时 `printf 0123456789ABCDEF` 的 Stdout 恰为 "0123456789"；
   e. MaxOutput=0 时按默认 1 MiB 处理：输出 2000 字节不被截断；
   f. ctx 200ms 超时运行 `sleep 5` → ExitCode 124，且 Run 在 3 秒内返回；
   g. ctx 200ms 超时运行 `sleep 5 & sleep 5`（后台子进程）→ 同样 3 秒内返回、ExitCode 124（验证进程组被整体杀掉）；
   h. workdir 为不存在的目录 → ExitCode 1，Stderr 非空。
3. `ReadMultipleFiles`：两个存在文件 + 一个不存在文件，结果顺序与输入一致、不存在的那项 Error 非空且 Content 为空；limit=4 时内容截断为前 4 字节；limit=0 或 > 1 MiB 时按 256 KiB 截断（用 300 KiB 文件验证长度为 262144）。
4. `CreateDirectory`："" 和 "   " 返回错误；多级路径创建成功且是目录。`MoveFile`：src 或 dst 为空返回错误；正常移动后源不存在、目标内容相同。
5. `SessionManager`：
   a. `NewSessionManager(0)`、`(-1)`、`(MaxSessionsPerManager+1)` 的上限都等于 MaxSessionsPerManager；`NewSessionManager(2)` 上限为 2，第 3 个 Start 返回含 "session limit reached" 的错误；
   b. 重复 id 的 Start 返回含 "session already exists" 的错误；
   c. Get 存在 / 不存在；Remove 存在返回 true、再次 Remove 返回 false；
   d. List 返回每个会话的 ID、Command，运行中的 Running=true，结束后 Running=false 且 ExitCode 正确；
   e. Stop 不存在的 id 返回 "session not found"；Stop(id,false) 和 Stop(id,true) 都能让 `sleep 30` 会话在 3 秒内结束（等 Done()）；
   f. Cleanup：未过期会话保留；已过期且已结束的会话被删除；已过期但仍在运行的会话被 Kill 且本轮保留、结束后再次 Cleanup 被删除。过期通过在测试里加锁把 ExpiresAt 设为过去实现，不要 sleep 等 TTL。
6. `Session.Stdin`：超过 MaxSessionInput 返回 "session input too large"；`cat` 会话写入 "ping\n" 后 Output() 在 3 秒内含 "ping"。`Session.Expired`：新会话为 false；ExpiresAt 设为过去为 true；LastAccess 早于 SessionIdleTTL 为 true。

所有等待都用 Done()/轮询加 3 秒上限，不允许无上限等待；测试结束要 Kill 自己启动的所有会话。

不做：不改任何非测试代码；不重构已有测试；不测 Diagnostic、EditBlock、Search、ListProcesses。如果某条要求测出实际行为与要求不符，不要改代码，在该子测试里 `t.Skip("BUG: ...")` 写清现象，并在完成回复里单独列出。
