二、要求（只加测试，不改 auth.go 的任何行为）
1. HasScope：Type 为 panel 或 system 时任意 scope 返回 true；Type 为 api_token 时，Scopes 中为 true 的返回 true，不存在的返回 false，Scopes 为 nil 时返回 false。
2. AllowsDevice：Devices 为 nil 或空 map 时任意设备返回 true；非空时只有列出的设备返回 true，其他返回 false；区分大小写（列了 node-01，NODE-01 返回 false）。
3. Expired：nil 返回 false；现在之前 10 秒返回 true；等于当前秒返回 true；现在之后 3600 秒返回 false。
4. PrincipalFromRequest，旧版令牌模式（NewManager）：
   a. 没有 Authorization 头返回 false；
   b. NewManager("secret-a") 且 Bearer secret-a：返回 true，Type=api_token，ID=legacy-env，Scopes["admin"]=true；
   c. Bearer 错误令牌返回 false；
   d. NewManager("") 时任何 Bearer 都返回 false。
5. PrincipalFromRequest，校验器模式（NewManagerWithValidator）：
   a. 校验器返回 ok 时，返回校验器给出的 Principal（比较 ID 和 Name）；
   b. 校验器返回 false 时返回 false，即使请求令牌等于构造时传入的旧版令牌（校验器优先，不回落到旧版令牌）；
   c. 校验器收到的 token 等于请求中的 Bearer 值，ip 等于 ClientIP(r) 的返回值。
6. Rotate：返回 48 位小写十六进制字符串；之后 Token() 返回同一个值；连续两次 Rotate 结果不同；Rotate 后旧令牌不能再通过 PrincipalFromRequest。
