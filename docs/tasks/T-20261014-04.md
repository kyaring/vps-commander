一、问题
1. 缺陷 1（安全）：只有 `Authorization: Bearer x` 和 `bearer=x` / `bearer: x` 会脱敏。单独出现的 bearer 令牌不会被脱敏，比如 curl -H "Bearer abc123"、日志里的 Bearer eyJ...、"token is Bearer abc, ok"，令牌会原样写进审计的 command / error_msg。生产现网审计库已核查：目前没有真实令牌泄露，只是缺这层防护。
2. 缺陷 1b（Hark 00:59 在节点上实测现行为）：`Authorization: Bearer abc123` → `Authorization: [REDACTED] [REDACTED]`，`authorization=bearer abc123` → `authorization=[REDACTED] [REDACTED]`，`-H "Authorization: Bearer abc"` → `-H "Authorization: [REDACTED] [REDACTED]`（右引号被吃掉）。原因是 secretRE 又把 "Bearer" 这个词当成 authorization 的值替换了一次。令牌没有泄露，但结果是重复的 [REDACTED]，还破坏了引号。
3. 缺陷 2：Redact 在 8192 字节处直接切片 value[:8192]，可能切断多字节 UTF-8 字符，写出非法 UTF-8。
4. 调用方：internal/api（tokens.go、token_limiter.go）、internal/mcp/mcp.go、internal/storage/storage.go 的 normalizeAuditEntry 都调用 Redact/Truncate，所以只改 auditutil 一处就全部生效，调用方不改。

二、要求
1. 任意位置的 bearer + 空白 + 令牌（不区分大小写，bearer 前必须是词边界，即 \bbearer\s+）都把令牌换成 [REDACTED]，保留原 bearer 的大小写写法和空白。令牌遇到空白、逗号、分号、单引号、双引号就结束。
2. 已经是 [REDACTED] 的不得再处理：`Authorization: Bearer x` 的结果必须恰好是 `Authorization: Bearer [REDACTED]`，不能出现 [REDACTED] 重复或嵌套（例如 [REDACTED]] 或 [REDACTED] [REDACTED]）。
3. 除 Authorization/Bearer 形式外，已有行为不变：`token=x` → `token=[REDACTED]`、`api_key: x` → `api_key: [REDACTED]`、`password=x` → `password=[REDACTED]`、`cookie: a=b` → `cookie: [REDACTED]`、`bearer: x` → `bearer: [REDACTED]`，与现在逐字一致；`\r`、`\n` 仍替换成空格；脱敏仍然在截断之前做。
4. 8192 字节上限不变，截断时向前退到最近的完整 UTF-8 字符边界：结果 utf8.ValidString 为真且长度不超过 8192 字节。不得改成按字符数计算。输入本身就含非法 UTF-8 时不必修复，只要求不再新切出半个字符。
5. Truncate（512 个字符）行为不变。
不做：不改调用方；不迁移历史审计行；不新增其他脱敏规则。

三、测试（新建 internal/auditutil/redact_fix_test.go，表驱动）
1. 单独 bearer 令牌会被脱敏，结果里不再出现原令牌：`Bearer abc123`、`bearer abc123`、`BEARER abc123`、`-H "Bearer abc123"`（引号保留）、`-H 'Bearer abc123'`、`token is Bearer abc123, ok`、`Bearer abc123;next`、句中多个令牌。
2. 词边界：`xbearer abc123` 不按 bearer 规则处理（它可能被其他规则处理，测试只断言不 panic、结果合法）。
3. `Authorization: Bearer abc123` → `Authorization: Bearer [REDACTED]`；`authorization=bearer abc123` → `authorization=bearer [REDACTED]`；`-H "Authorization: Bearer abc"` → `-H "Authorization: Bearer [REDACTED]"`（右引号保留）。三者都要求 strings.Count(result, "[REDACTED]") == 1。
4. 回归：要求 3 列出的五种输入，输出与修改前逐字相同（在测试里写明期望字符串）。
5. 8191 个 ASCII 加一个 3 字节汉字：结果 utf8.ValidString 为真，长度不超过 8192 字节（应为 8191）。
6. 8190 个 ASCII 加一个 4 字节 emoji：结果合法且长度为 8190。
7. 恰好 8192 字节纯 ASCII 原样保留；8193 字节截成 8192。
8. Truncate：513 个汉字 → 511 个加 "…"，512 个原样。
