一、目标
1. initialize 响应返回服务器级 instructions，内容短（不超过 1500 字符），只写协议级约定：
   - 设备名只能来自 list_devices，不传 device 时在 Hub 所在节点执行；
   - 同步 exec_command 有时长上限，超过的任务用 exec_start 与 exec_status 轮询；
   - 破坏性操作（删除、覆盖、停止服务）执行前先确认目标；
   - 大输出用 read_file 的 @hub-spill 分段读取；
   - 不得把令牌或密钥写入命令或便签。
   instructions 必须与当前令牌的可见工具一致：令牌看不到的工具，相关说明不出现。
2. 每个工具补充 annotations：
   - 只读工具（list_devices、read_file、read_multiple_files、list_processes、diagnostic_command、list_agent_mcp、exec_status、memo_get）：readOnlyHint=true；
   - 有副作用的工具（exec_command、exec_start、exec_cancel、write_file、edit_block、create_directory、move_file、call_agent_mcp、memo_set）：destructiveHint 按实际副作用标注，readOnlyHint=false；
   - 所有工具都标注 openWorldHint（访问外部节点为 true，仅访问 Hub 本地状态为 false）。
   标注值依据工具的真实行为，不得为了让客户端少确认而虚报。

- TestAnnotationsDestructiveToolsNotReadOnly：有副作用的工具 readOnlyHint 为 false。
- tools_list 哈希测试：更新常量为新值，并注明变更原因。
