一、目标
1. runner 删除 D5 的单一提供商兜底：不再读取 MODEL_API_BASE、MODEL_API_KEY。runner.env 不再需要网关 key；runner 的 Hub 地址必须是 https://（本机回环地址 127.0.0.1 可用 http，但需要显式配置 RUNNER_ALLOW_LOOPBACK_HTTP=1）。否则启动失败并给出明确错误。
2. 领取任务后，对每一轮模型调用前，runner 调用 POST /api/v1/devtask-runner/credentials（T-20261028-10 定义）取得 base_url 与 api_key：
   - 仅保存在进程内存的结构体中，任务结束或租约到期时清零；
   - 不写入磁盘、临时文件、任务结果、日志、错误详情、测试快照；
   - 同一任务的一个租约内可以缓存凭据，租约续期后重新取得。
3. 返回 provider_not_configured 或被 Hub 拒绝时，任务进入 blocked_model，error_code 为 provider_not_configured 或 credential_denied（按 HTTP 状态区分），不尝试其他提供商，也不调用模型。
4. 模型调用只使用 credentials 返回的 base_url；不得使用任何环境变量中的 URL 或 key。
5. 日志只输出 task_id、provider_id、model、HTTP 状态码与错误码；不输出 base_url、api_key、Authorization 头。

二、测试（每条至少一个用例）
- TestRunnerRefusesHTTPHubURL：Hub 地址为 http:// 且非回环配置时启动失败。
- TestRunnerIgnoresLegacyEnv：设置 MODEL_API_BASE 与 MODEL_API_KEY 时，runner 不使用它们，假服务收到 0 次请求。
- TestRunnerFetchesCredentialsAtClaim：每个任务在第一次调用模型前取得凭据，假 Hub 记录到一次取凭据请求，携带正确的 task_id、lease_id、provider_id、model。
- TestRunnerCredentialDeniedBlocksWithoutFallback：假 Hub 返回 403 时，任务进入 blocked_model（credential_denied），假模型服务收到 0 次请求。
- TestRunnerProviderNotConfiguredBlocks：假 Hub 返回 409 provider_not_configured 时进入 blocked_model。
- TestRunnerCredentialsNotOnDisk：整个运行过程中扫描工作目录、临时目录与数据目录，搜索测试 api_key 的字节序列，结果为空。
- TestRunnerLogsContainNoSecret：标准输出、标准错误、任务结果中搜索测试 api_key 与 base_url，结果为空。
- TestRunnerClearsCredentialsOnLeaseEnd：租约结束后，内存中的凭据结构体被清零（通过测试钩子检查）。
