## 背景
来自 T-20261015-03 审核报告里的建议 1、2（docs/reviews/T-20261015-03-review.md）。T-03 已经给测试的日志 buffer 加了锁，但还有两个缺口：
- 没有确定性的回归保护：把锁去掉以后，只会在全仓 race 中偶发报红，测试拦不住。

## 必改
1. 给 synchronizedLogBuffer 写一个确定性的并发测试：多个 goroutine 同时调用 Write 和 String，在 `-race` 下必须稳定通过；把锁去掉以后，必须稳定报 DATA RACE。
2. 给哨兵断言加自检：先断言日志 buffer 确实捕获到了这次请求的日志（例如包含 memo 的 key 或一条已知日志），再断言不含 memo 值。
3. 不改业务代码，也不改动 T-03 已有断言的语义。
