## 二、执行方式（按模块逐个摘取，不要整分支 rebase）

推荐用 `git checkout <branch> -- <path>` 逐模块取文件，再按需修冲突；**不要**对四个分支整体 rebase。

### 步骤 1：建分支并先落地 D4（MCP 工具）

