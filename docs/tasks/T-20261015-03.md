## 背景
Hark 在 T-20261015-02 终签时，全仓跑 `-race -shuffle=on` 出现过一次 DATA RACE（大约 13 轮 1 次）。位置是 `internal/api/session_memo_test.go:224`：它用 `slog.SetDefault` 把全局日志换成一个没有加锁的 bytes.Buffer，而之前用例留下的 `storage.auditWriter` 后台 goroutine 还在往全局日志里写（storage.go:615 的 log.Printf）。详情见 docs/reviews/T-20261015-02-review.md 末尾的「Hark 终签」一节。

## 必改
1. 测试用的日志 writer 要加锁（自己写一个带 mutex 的 writer，Write 和 String 都加锁），或者换一种不依赖全局 slog 的断言方式。不能删掉「日志里不得出现 memo 值」这条断言。
2. 如果别的测试里也有同样的「全局 slog/log 换成未加锁 Buffer」写法，一并修掉。用 `grep -rn "SetDefault\|log.SetOutput" --include=*_test.go` 排查，并在交付说明里列出结果。
3. 不改业务代码。如果确实需要给 storage 加一个测试用的「等待后台审计写完」接口，在交付说明里写明理由。
