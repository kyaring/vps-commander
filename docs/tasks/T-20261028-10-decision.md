# 决策备忘：DevTask 模型 URL 与 API Key 的存放位置

背景：管理员希望在管理面板中直接填写模型提供商的 API URL 与 API Key。

现行规格（devtask-v1.1.36-taskbook.txt）：
- 第 39 行：网关 key 和长任务都不进 Hub 进程；
- 第 117 行：网关地址与 key 只放在 runner 本机的 /etc/devtask/runner.env（属主 devtask，600），模型名来自任务。

方案 A（推荐先做，对应任务卡 T-20261028-10）
- Hub 只存非密钥的提供商登记（ID、显示名、启用状态）。
- URL 与 Key 仍在 runner 本机环境变量中，按提供商分别配置。
- 面板不能填写 URL 与 Key；换地址或换 key 要改 runner.env 并重启 runner。
- 不需要修改规格。

方案 B（需要 OPC 批准规格变更）
- Hub 用 AES-256-GCM 加密保存 URL 与 Key（可复用通知密钥的加密方式），面板可直接编辑。
- Hub 进程会持有模型 key，违背规格第 39 行，必须修订规格，并由 Hark 审核安全边界。

需要 OPC 决定：
1. 选择方案 A 或方案 B。
2. 若选 B，批准规格变更，并确定加密主密钥的来源（不得放在仓库或数据库中）。
3. 确认 T-20261028-10 的依赖顺序（D3–D6、DevTask B 先合并）。
