## 一、问题

以下行为在卡 01、02、04 中已经改变，但文档仍是旧描述：
1. read_multiple_files 截断时新增 truncated 字段，且读取上限是流式的；
2. edit_block 跟随符号链接，悬空链接报错，硬链接拒绝编辑（返回 hardlinked file refused）；
3. Agent 与 Hub 的 file_write 改为原子写入：临时文件 + rename，保留已有文件的权限与属主，新建文件固定 0644，符号链接写入真实目标，硬链接与非普通文件被拒绝；
4. 一次性 exec 的等待上限为 2 秒（WaitDelay），后台子进程占着管道时命令按退出码结算；
5. search 跳过大于 10 MiB 的文件与前 8 KiB 含 NUL 的二进制文件。
