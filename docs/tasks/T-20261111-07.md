## 一、背景
1. **审计日志 `timeout` 缺少彩色框与筛选项**：
   - 当 `exec_command` 超时（`context.DeadlineExceeded`）时，`internal/api/mcp_adapter.go:124-126` 会写入 `result = "timeout"`（`exit_code = 124`）。

   - 同时 `internal/web/static/index.html:136` 的「结果」筛选下拉框 `<select id="auditResult">` 也缺少 `timeout` 选项。
2. **`release-build.sh` 未包含 GitHub Release 对应的 `vc-agent` 多架构产物**：

   - 现行 `scripts/release-build.sh` 仅编译了 `vps-commander-hub`（`linux/amd64`），未编译 `cmd/agent` 的三个架构版本。
