一、目标（对照 taskbook §3–§5 与提交拆分第 3 条）

1. storage：任务 CRUD / 列表 / 租约 / 事件
   - CreateDevTask：写入 queued；校验 project 存在且 enabled；model 必须在白名单（调用方传入已解析模型）；id 由 API 层生成后传入；branch 固定为 `task/<id>`；round 初始 1；把 accept/allowed/forbidden JSON、max_*、actor 字段落库。
   - GetDevTask / ListDevTasks：支持按 project、status 过滤与 limit/offset 分页（默认 limit 50，最大 200）。
   - ClaimDevTask：原子领取一条 queued（或 running 且 lease_until 已过期）的任务；写入 claimed_by、lease_until=now+leaseSec、heartbeat_at、status=running、started_at（若首次）；同 claimed_by 已持有未完成任务时仍可续领过期单（并发先限 1 由 runner 侧保证，本层不做全局互斥）。
   - HeartbeatDevTask：仅 claimed_by 匹配且 status=running 时续租；否则 409/拒绝。
   - CompleteDevTask：runner 提交结果；合法迁移 running→needs_review|failed|blocked_model；写入 commit_sha、diff_stat、test_summary、result_md、error_code、error_detail、finished_at；清空租约字段。
   - CancelDevTask：任意未终态 → cancelled；写 finished_at；清空租约。
   - ReviseDevTask：needs_review 或 failed → queued，round+1；超过 max_rounds 拒绝；清空结果字段中适合重跑的部分（error_*、commit_sha 等由 API 约定），保留 spec 与模型。
   - MarkDoneDevTask：needs_review → done。
   - RequeueExpiredLeases：running 且 lease_until<now → queued（并可选记录 requeue 次数；超过 2 次 → failed，error_code=lease_expired）。若尚无 requeue 计数列，用 error_detail 前缀或单独列 `lease_requeues`（若加列须在 migrate 中 IF NOT EXISTS / 兼容已有库）。
   - AppendDevTaskEvents / ListDevTaskEvents：按 task_id+seq；payload 截断 8KiB；List 支持 after_seq 与 limit。

2. REST 用户接口（均在 DEVTASK_ENABLED 门闩后；scope 如下）
   - POST /api/v1/devtasks — submit：body 含 project、title、spec_md、accept_cmds?、allowed_paths?、forbidden_paths?、model?；校验项目 enabled、model 在白名单（缺省用项目 default_model）；写审计 action=devtask_dispatch。
   - GET /api/v1/devtasks — read：query project、status、limit、offset。
   - GET /api/v1/devtasks/{id} — read。
   - GET /api/v1/devtasks/{id}/events — read：query after_seq、limit。
   - POST /api/v1/devtasks/{id}/revise — submit：body 可含 note；needs_review|failed 才可；写审计。
   - POST /api/v1/devtasks/{id}/cancel — cancel；写审计。
   - POST /api/v1/devtasks/{id}/done — submit 或 admin：needs_review→done；写审计。
   - 本卡不做 diff 文件内容接口（可留空 501 或下卡）；若易做可返回占位 {"diff":"","note":"runner supplies commit_sha"}。

3. Runner 专用接口（requireScope("devtask:run")）
   - POST /api/v1/devtasks/claim — body 可选 claimed_by（默认用 token id）；返回任务全文或 204/404 无任务。
   - POST /api/v1/devtasks/{id}/heartbeat — 续租。
   - POST /api/v1/devtasks/{id}/events — 批量追加事件（数组，每条 type+payload）。
   - POST /api/v1/devtasks/{id}/complete — body：status(needs_review|failed|blocked_model)、commit_sha?、diff_stat?、test_summary?、result_md?、error_code?、error_detail?。

4. 开关与路由挂载：与 D2 相同 devtaskGate；挂到 Routes()。

5. 不做：MCP 工具、runner 进程、面板、通知、真实模型调用、merge/push/deploy。
