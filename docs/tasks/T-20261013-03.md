2. deploy/deploy-hub-local.sh <二进制路径> --sha256 <hex> [--dry-run]
   - 校验 sha256 与参数一致，不一致退出 1，什么都不改。
   - 备份到 <BACKUP_ROOT>/backup-pre-<新二进制 sha256 前 12 位>-<YYYYmmddHHMMSS>/：旧二进制 + 数据库在线备份（用 sqlite3 "<DB>" ".backup '<目标>'"，不得直接 cp 正在写的 DB）。备份失败立即退出，不替换。

   - 健康失败：自动恢复旧二进制并重启，再次检查；成功打印 `ROLLBACK OK backup=<dir>` 并退出 1，失败打印 `ROLLBACK FAILED backup=<dir>` 并退出 2。数据库不自动回滚，只打印手动恢复命令。

   - --dry-run：只校验和打印将执行的步骤，不写任何文件、不调 systemctl。
